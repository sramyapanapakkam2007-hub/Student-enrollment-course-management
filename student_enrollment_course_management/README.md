# Student Enrollment & Course Management System

## Technology
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Authentication: JWT

## Modules
1. Admin authentication
2. Student management
3. Course management
4. Enrollment management
5. Dashboard
6. Validation and error handling

## Run
### Database
1. Create a MySQL database.
2. Run `phase-03-database/schema.sql`.

### Backend
```bash
cd phase-04-backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd phase-05-frontend
npm install
npm run dev
```

Default frontend URL: http://localhost:5173
Default backend URL: http://localhost:5000
