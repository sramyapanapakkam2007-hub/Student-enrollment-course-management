# Phase 1 - Requirements

## Objective
Build a system that allows an administrator to manage students, courses and student enrollments.

## Functional Requirements
- Admin login/logout
- Add, view, edit and delete students
- Add, view, edit and delete courses
- Enroll a student into a course
- Prevent duplicate enrollment
- Prevent enrollment when course capacity is full
- View enrollment history
- Dashboard statistics

## Non-Functional Requirements
- Responsive UI
- REST API architecture
- Secure password storage
- Server-side validation
- Relational database
- Clear error messages

## Main Actors
- Admin
- Student (managed by admin)

## Core Entities
Admin, Student, Course, Enrollment
